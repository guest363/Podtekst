# Политика конфиденциальности

Приложение «Запись встреч» работает локально. Оно не отправляет аудио,
расшифровки, голосовые отпечатки, списки участников или статистику на серверы
проекта. Телеметрии нет.

## Какие данные хранятся

* аудио- и видеофайлы записей — в выбранной пользователем папке
  (`~/Recordings` по умолчанию);
* расшифровки `.md`, `.txt`, `.transcript.json` — рядом с записями;
* голосовые отпечатки, участники и настройки — в папке данных приложения
  (`~/.local/share/meeting-recorder` на Linux);
* скачанные веса моделей — в `<app_data>/models`.

Все эти данные остаются на компьютере пользователя. Приложение не шифрует их
самостоятельно: защита диска и резервное копирование — ответственность ОС и
пользователя.

## Сетевые запросы

Исходящий трафик только по HTTPS:

* скачивание открытых весов моделей с Hugging Face и GitHub;
* проверка последней версии приложения через GitHub Releases (без аудио,
  текстов и идентификаторов пользователя).

Запросы содержат только стандартные HTTP-заголовки; SHA-256 скачанных моделей
проверяется.

## Удаление данных

Свои записи, созданные приложением, удаляются из интерфейса вместе с
расшифровкой. Файлы, добавленные в папку записей извне, при удалении из
интерфейса остаются на диске — приложение убирает только ссылку на них.

Удалить записи можно и вручную. Папку данных приложения можно удалить целиком —
при следующем запуске она создастся заново.
