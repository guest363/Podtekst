## Ключевые возможности

- **Раздельный захват:** на компьютере ваш микрофон записывается в левый канал, системный звук звонка - в правый (PipeWire / PulseAudio / WASAPI Loopback). Голоса не накладываются друг на друга: это повышает точность расшифровки и позволяет слушать собеседников отдельно.
- **100% офлайн и приватность:** распознавание работает локально через ONNX Runtime на процессоре ноутбука или телефона. Данные аудио, текст и цифровые отпечатки голоса не отправляются во внешнюю сеть.
- **Русский язык SOTA (GigaAM-v3):** модель от SberDevices с квантованием весов в INT8 (всего 226 МБ). Распознает русскую речь быстро и без дискретной видеокарты.
- **Мультиязычность (Whisper Turbo):** модель Whisper large-v3-turbo (INT8, ~1.08 ГБ) для встреч на английском и ещё 30+ языках.
- **Диаризация и узнавание коллег:** модель ERes2NetV2 (3D-Speaker) разбивает дорожку на реплики и узнаёт знакомые голоса по сохранённым профилям (Voice Packs).
- **Синхронная запись экрана (Linux):** запись рабочего стола или окна звонка параллельно с микрофоном и системным звуком в единый MP4-файл без нагрузки на процессор (нативный захват GNOME Shell / PipeWire). Во встроенном плеере видео воспроизводится синхронно с репликами и таймкодами (пока протестировано на Linux; macOS и Windows — в разработке).
- **Готовые конспекты для базы знаний:** после остановки записи рядом с файлом автоматически создаются:
  - `.md` - читаемый протокол со спикерами и таймкодами (для Obsidian, Notion, Logseq);
  - `.txt` - чистый текст для отправки в локальные языковые модели;
  - `.transcript.json` - структурированные реплики, таймкоды и 192-мерные векторы голосов.

| Платформа | Живой захват аудио | Запись экрана | Импорт файлов и видео | Статус |
| :--- | :---: | :---: | :---: | :--- |

## Быстрый старт

### Вариант 1. Готовые сборки
Скачайте исполняемый файл для вашей операционной системы со страницы [Releases](https://github.com/guest363/podtekst/releases):
- **Linux:** `.AppImage`
- **macOS:** `.dmg` (или запуск через `run.command`)
- **Windows:** `.exe` (или запуск через `run.bat`)

#### macOS: если после установки «невозможно открыть»

Пока релиз не подписан Apple Developer ID, Gatekeeper блокирует скачанный
`.dmg`. Снимите карантин у скопированного в `/Applications` приложения один раз:

```bash
xattr -dr com.apple.quarantine /Applications/Podtekst.app
open /Applications/Podtekst.app
```

То же самое можно сделать без терминала: правый клик по приложению →
**«Открыть»** → **«Открыть»** в диалоге. При первом запуске macOS спросит
доступ к микрофону - разрешите его в «Системные настройки» → «Конфиденциальность
и безопасность» → «Микрофон».

Когда в CI заданы секреты `APPLE_CERTIFICATE`, `APPLE_SIGNING_IDENTITY`,
`APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID`, сборка подписывается и
нотаризуется, и снимать карантин вручную не нужно.

#### macOS: звук собеседников

CoreAudio не отдаёт системный звук без виртуального драйвера. Чтобы писать
собеседников из Zoom/Meet/Telegram отдельным каналом:

1. Установите **BlackHole 2ch**: `brew install blackhole-2ch`.
2. В «Настройке Audio-MIDI» создайте **многовыходное устройство** из ваших
   наушников/динамиков и BlackHole (наушники - ведущее устройство).
3. Выберите это устройство выходом звука в macOS.
4. Приложение само увидит BlackHole как источник системного звука и предложит
   режим «Встреча · 2 канала».

Без BlackHole (или аналогичного Loopback/Soundflower) запись идёт только с
микрофона в один канал - интерфейс скрывает второй канал.

### Вариант 2. Запуск из исходников

```bash
git clone https://github.com/guest363/podtekst.git
cd podtekst
./run.sh
```

Приложение откроется в нативном окне. Для запуска в режиме веб-сервера без системных GUI-зависимостей (WebKit/GTK):

```bash
./run.sh --web
```

Консоль управления доступна в браузере по адресу `http://127.0.0.1:8765`.

### Системные требования

- **Процессор:** любой современный x86_64 или Apple Silicon.
- **macOS на Apple Silicon:** запускайте нативную arm64-сборку. x86_64-бинарник
  под Rosetta работает, но ONNX-расшифровка замедляется в разы; `run.command`
  предупреждает об этом.
- **Оперативная память:** от 1.5 ГБ RAM для GigaAM-v3; от 4 ГБ свободной RAM при расшифровке через Whisper.
- **Диск:** ~300 МБ для базовых моделей (Silero VAD + GigaAM + 3D-Speaker); ~1.4 ГБ с Whisper.
- **Linux:** Ubuntu 22.04+ / glibc 2.35+; для сборки нативного окна требуются системные библиотеки:
  ```bash
  sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev
  ```
- **Поддержка форматов:** MP3, WAV, M4A, OGG, Opus, FLAC и MP4 декодируются нативно через библиотеку Symphonia. Для видеоконтейнеров MKV, WebM, MOV, AVI используется системный `ffmpeg` (если установлен).

## Локальный ИИ-конвейер

Обработка аудиопотока выполняется на 100% локально через **ONNX Runtime (CPU)** без дискретной видеокарты:

```
Аудиодорожка (16 кГц)
   │
   ▼
[Silero VAD v6] ──────────► Нарезка аудио на речевые фрагменты без пауз и шума
   │
   ├──────────────────────────────┬──────────────────────────────┐
   ▼                              ▼                              ▼
[GigaAM-v3 e2e RNNT]   [Whisper large-v3-turbo]        [ERes2NetV2 3D-Speaker]
(Основной ASR, RU, 226 МБ) (30+ языков, INT8, 1.08 ГБ) (Голосовые векторы, 68 МБ)
   │                              │                              │
   └───────────────┬──────────────┘                              ▼
                   ▼                                  Венгерская кластеризация
            Текст реплик ───────────────────────────► Итоговый Markdown / JSON
```

### Характеристики используемых моделей

| Модель | Назначение | Архитектура и веса | Память (RAM) | Особенности | Лицензия |
| :--- | :--- | :--- | :---: | :--- | :---: |
| **GigaAM-v3 e2e RNNT** | Основной ASR (RU) | Conformer-Transducer 242M, **INT8** (226 МБ) | ~600 МБ | SOTA для русской речи, жадный RNNT-декодинг | MIT |
| **Whisper Turbo** | Мультиязычный ASR | Seq2Seq Transformer, **INT8** (1.08 ГБ) | ~3.8 ГБ | 30+ языков, сжатый 4-слойный декодер | MIT |
| **Silero VAD v6.2** | Детектор речи | Потоковая рекуррентная сеть (2.3 МБ) | ~15 МБ | Окно 32 мс, фильтрация вздохов, кликов и эха | MIT |
| **ERes2NetV2 3D-Speaker** | Отпечатки голоса | ERes2NetV2 17.9M, FP32 (68 МБ) | ~120 МБ | 192-мерные L2-векторы, точность на отрезках от 1.5 с | Apache-2.0 |

<details>
<summary><strong>Подробнее об обновлении моделей и голосовых пакетах</strong></summary>

1. **Манифест моделей (`models-manifest.json`):** Версии файлов, официальные зеркала (HuggingFace / ModelScope) и контрольные суммы SHA-256 зафиксированы в коде приложения. При скачивании файл пишется во временный `.part` и подменяется атомарно только после совпадения контрольной суммы.
2. **Голосовые пакеты (Voice Packs):** Базы контактов и биометрических профилей хранятся независимо от кода в `<app_data>/packs/<id>/` (`people.json`, `voiceprints.json` v3, `snippets/*.wav`). Их можно экспортировать в `.voicepack.zip` и передавать коллегам.
3. **Совместимость версий (`embedding_space`):** При изменении архитектуры модели эмбеддингов старые несовместимые профили архивируются в резервную копию, предотвращая ошибки кластеризации.
</details>

## Управление и горячие клавиши

Глобальный хоткей (работает из любого окна):  
**`Ctrl+Shift+R`** (на macOS - **`Cmd+Shift+R`**) - начать или остановить запись.

### Команды CLI и автоматизация

```bash
./run.sh --toggle      # Переключить запись (удобно для привязки к системному хоткею)
./run.sh --start       # Начать запись
./run.sh --stop        # Остановить запись
./run.sh --tray        # Фоновый режим в системном трее
./run.sh --web         # Открыть веб-интерфейс в браузере

# Пакетная расшифровка аудиофайла без запуска интерфейса:
./run.sh --transcribe meeting.mp3 [--engine auto|gigaam|whisper]
```

## Приватность и безопасность

- **Локальная обработка без отправки данных:** все нейросети работают строго локально на вашем процессоре.
- **Отсутствие телеметрии:** приложение не собирает аналитику, логи использования или списки участников.
- **Сетевой трафик:** происходит только в двух случаях:
  1. Однократная загрузка открытых весов моделей с официальных репозиториев авторов (HuggingFace/ModelScope) по прямой команде пользователя.
  2. Проверка версии на GitHub при запуске. Загрузка подписанного обновления (Linux: AppImage, macOS: `.app`, Windows: установщик NSIS) запускается только по кнопке. Без согласия пользователя ничего не устанавливается.

> **Внимание:** соблюдайте законы о конфиденциальности и предупреждайте собеседников о ведении записи разговора. Подробнее - в [PRIVACY.md](PRIVACY.md).

## Разработка и участие

Стек: **Rust** (MSRV 1.92, Tokio, Symphonia, Ort) + **Tauri v2** + **Svelte 5** (Vite, TypeScript).

```bash
# Запуск тестов ядра и математики диаризации
cargo test --workspace --locked --manifest-path src-tauri/Cargo.toml

# Проверка кода линтером (строгий режим без предупреждений)
cargo clippy --workspace --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings

# Проверка типов и сборка фронтенда
cd ui/web/frontend && yarn install --immutable && yarn check && yarn build
```

Подробное описание архитектуры, внутренних крейтов и правил разработки находится в [AGENTS.md](AGENTS.md). Правила участия в разработке - в [CONTRIBUTING.md](CONTRIBUTING.md).

## Стоя на плечах великих

Наше приложение работает локально и без подписок только благодаря исследователям и инженерам, открывшим свои модели и код миру. Мы искренне благодарны авторам проектов и библиотек:

### Модели и исследования
- [GigaAM](https://github.com/salute-developers/GigaAM) (SaluteDevices / Sber AI) - за открытые веса и качественное распознавание русской речи, работающее быстро даже на процессоре ноутбука.
- [Whisper](https://github.com/openai/whisper) (OpenAI) - за мультиязычную архитектуру, позволяющую расшифровывать встречи на десятках языков без отправки звука на чужие серверы.
- [Silero VAD](https://github.com/snakers4/silero-vad) (Silero Team / Александр Вейсов) - за быстрый детектор речи, который отсекает паузы и бережёт ресурсы компьютера.
- [3D-Speaker & ERes2NetV2](https://github.com/alibaba-damo-academy/3D-Speaker) (Alibaba Tongyi Speech Lab / ModelScope) - за качественные модели голосовых отпечатков, позволяющие разделять и узнавать собеседников.
- [ONNX Runtime](https://onnxruntime.ai/) (Microsoft) - за производительный движок, выжимающий максимум скорости из обычного процессора.

### Библиотеки Rust
- [ort](https://github.com/pykeio/ort) - за надёжные привязки к ONNX Runtime, открывшие путь нейросетям в безопасный код на Rust.
- [symphonia](https://github.com/pdeljanov/Symphonia) - за декодер звука на чистом Rust, избавивший проект от громоздких C-зависимостей FFmpeg.
- [hound](https://github.com/ruuda/hound) - за простую и стабильную работу со звуком формата WAV.
- [opus-decoder](https://github.com/shogo4204/opus-decoder) - за прямое чтение голосовых заметок из Telegram и других мессенджеров.

### Платформа и интерфейс
- [Tauri](https://tauri.app/) - за легковесную архитектуру без оверхеда Electron, благодаря которой бинарник весит считанные мегабайты.
- [Svelte](https://svelte.dev/) - за отзывчивый интерфейс без виртуального DOM и удовольствие от разработки.
