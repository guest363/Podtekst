# mr-models - AGENTS.md

Крейт управления каталогом ИИ-моделей, валидации контрольных сумм и фоновой загрузки.

## 1. Архитектура и строгие инварианты

- **Единый источник истины:** манифест `models-manifest.json` содержит канонический список моделей, официальные зеркала (Hugging Face / ModelScope) и контрольные суммы SHA-256 (P1).
- **Безопасная загрузка:** скачивание выполняется во временные файлы `.part`. Замена на рабочий `.onnx` файл происходит атомарно только после успешной проверки SHA-256.
- **Возобновление загрузки:** поддерживается докачка частично скачанных файлов при обрыве соединения по заголовку `Range`.
- **Локальное хранение:** скачанные веса хранятся строго в `<app_data>/models/<id>/`.

## 2. Ключевые файлы

- `src/lib.rs` - реестр моделей, загрузчик по HTTPS, проверка целостности файлов и отслеживание прогресса.
- `models-manifest.json` - встроенный канонический манифест версий моделей.

## 3. Локальная верификация

```bash
# Юнит-тесты валидации манифеста и парсинга
cargo test -p mr-models --lib

# Строгая проверка clippy
cargo clippy -p mr-models --all-targets --locked -- -D warnings
```
