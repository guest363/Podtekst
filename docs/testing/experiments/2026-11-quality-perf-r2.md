# Эксперимент R2: качество, сегментация и скорость (ноябрь 2026, раунд 2)

Статус: локальный эксперимент. Это не контракт и не замена `SPEC.md`; числа
получены на одной машине и одной серии прогонов.

## Методика

- Ветка `experiment/quality-perf-r2`, база `7839d7b`, чистое дерево.
- Прогоны с `--data-dir` на изолированном каталоге: без личных `voiceprints.json`
  и `hotwords`, иначе WER/DER невоспроизводимы.
- Модели: GigaAM-v3 RNNT int8 + CTC, Whisper turbo, Silero VAD, PyAnnote 3.0,
  ERes2NetV2 192.
- Наборы: `small` 10, `synth-distinct` 4 (клипы 00/02/03 — разные голоса),
  VoxConverse 3 + длинные sxqvt/xmyyy, Golos crowd/farfield и main RU для ASR,
  perf suite.
- Raw WER (`metrics.csv`) и `WER_norm` (`normalize_wer.py`: числа → `<num>`,
  латиница → кириллица, огласовка) считаются отдельно.

## Итерации

1. **Baseline и диагностика.** Fresh-прогоны `small`, `synth-distinct`, Vox3.
   Fixed-k=3 на s3-120 показал, что эмбеддинги разделяют похожие голоса:
   DER 36.36 → 15.87, cpWER 55.75 → 7.08, attribution 73.2 → 98.2. Значит,
   ошибается не атрибуция, а auto-k.
2. **Auto-k по пороговому разбиению.** В `cluster.rs` правило разрыва теперь
   доверяет пороговому разбиению, если оно подтверждает на 1–2 кластера больше
   и gap_k ≥ 2. На s3-120 это даёт те же 15.87 / 7.08 / 98.2. Silhouette даёт
   k=3, но с margin 0.013 ниже порога 0.02; ручной порог 0.48 не меняет
   s3-120. Оба варианта отброшены.
3. **ASR-диагностика.** Сырой WER на Golos — в основном формат чисел и
   латиницы, а не потеря речи. Нормализованный WER 3.9–9.8%; потерь на
   VAD-краях и стыках нет, CTC не меняет слова, фронтенд GigaAM v3 — шум.
   Кода нет, отчёт `2026-11-asr-wer-diagnosis.md`.
4. **Скорость.** Профиль diar: segmentation 5%, split_pass 29%,
   units_build 63%, cluster 0%. Пропуск split_pass по свидетельству PyAnnote
   регрессировал EN cpWER (0.761 → 0.830), откатан. Принята дедупликация
   одинаковых якоря и окна короткой реплики: EN 15.1 с diar −19.4%, 60-с
   встреча rtf_norm −14.1%, A/B aggregate 0.881; small/Vox/distinct без
   изменений.
5. **Гейт и ревью.** Small 10/10 идентичен базе, Vox3 и длинный Vox без
   изменений, моно-файлы 1 спикер, EN cpWER 0.761 без регресса. OCR review:
   2 файла, 0 замечаний. `check.py --suite small` exit 0, `verify.sh --fast
   --rust` OK (fmt, clippy, тесты workspace).

## ASR

| Набор | raw WER база | WER_norm база |

| Golos farfield 50 | 7.00 | 4.53 |
| FLEURS-ru 50 | 5.31 | 4.09 |

Сырой WER доминируется числами: эталон Golos пишет числа словами, приложение —
цифрами. В заявленных 24 файлах crowd 11 нормализованных ошибок на 112 слов:
4 бренда/имени, 2 падежа, 2 число/аббревиатура, 2 удаления в середине фразы,
1 фонетическая замена; ни одной потери на краю. Потерь на краях VAD/стыках нет:
1 удаление на 344 нормализованных словах crowd+farfield, 0 в main RU. CTC off/auto
даёт одинаковый текст. Фронтенд GigaAM v3 (periodic Hann, continuous mel, без
preemphasis): crowd 33 = 17.24 → 17.24, farfield 32 = 9.38 → 8.33 (−2 слова),
FLEURS 20 = 6.87 → 6.87; в пределах шума, откатан.

Вывод: сравнивать с публикацией 2.4/3.9% можно только по `WER_norm` и на
одинаковом сплите; сырой WER стенда для Golos измеряет формат, а не речь.

## Скорость

Профиль 60-с встречи (под нагрузкой, относительные доли):

| Стадия | мс | доля diar |
|---|---:|---:|
| segmentation | 2114 | 5% |
| split_pass | 11947 | 29% |
| units_build | 25745 | 63% |
| cluster | 0 | 0% |
| diar всего | 41020 | 100% |

`units_build` — 66 чанков / 1.72 M сэмплов = 107 с аудио на 60 с файл.
`split_pass` на этой встрече не сделал ни одного разреза, но потратил 11.9 с.
Пропуск split_pass по PyAnnote регрессировал EN cpWER, поэтому не принят.
Принята только дедупликация: якорь и окно короткой реплики (≤2.4 с) — один и
тот же срез, второй инференс не нужен.

Парный A/B (5 повторов + прогрев, чередование base/main, калиброванный):

| Файл | diar_ms base → итог | rtf_norm base → итог |
|---|---:|---:|
| EN 15.1 с | 2808 → 2265 (**−19.4%**) | 78.9 → 70.6 |
| RU 15.6 с | 3185 → 3186 (0%) | 33.1 → 33.1 |
| RU встреча 60 с | 8869 → 8750 (raw −1.3%) | 21.2 → 18.2 (**−14.1%**) |
| A/B aggregate | **diar 0.861** (CI95 0.766–0.994) | **total 0.881** (CI95 0.713–1.023) |

На 60-с встрече у нового бинарника калибровка была на 23% выше (фоновая
нагрузка), поэтому сырой `diar_ms` занижает выигрыш; калиброванный `rtf_norm`
показывает −14%. Медиана `perf.py capture` не двигается, потому что медианный
файл набора — 15.6-с RU-клип без коротких дублей; честная оценка — A/B
aggregate 0.881. Small/Vox/distinct при этом бит-в-бит совпадают с базой:
дедупликация не меняет векторы.

Следующий большой рычаг — переиспользовать эмбеддинги split_pass как
акустические юниты (сейчас одно и то же аудио эмбеддится дважды). Это отдельная
задача: нужно выровнять окна/шаг и проверить small/Vox/distinct.

## Отрицательные результаты

- Silhouette-выбор k: на синтетике выбирает 3 (0.956 против 0.784); на реальных
  эмбеддингах s3-120 даёт 3, но margin 0.013 < 0.02, поэтому не проходит порог
  уверенности. Отброшен.
- Ручное понижение `CORE_LINKAGE_THRESHOLD` 0.51 → 0.48: s3-120 не меняется.
- Пропуск split_pass по PyAnnote: EN cpWER 0.761 → 0.830 (2 → 1 спикер),
  в том числе при ограничении ≤6 с; откатан.
- Фронтенд GigaAM v3 без preemphasis / periodic Hann / continuous mel: шум.
- Расширение VAD/границ для DER: +1–2 п.п. DER, но FA растёт; не окупается.

## Риски

- `MAX_THRESHOLD_EXTRA=2` откалиброван на одном файле s3-120; правило
  включается только при gap_k ≥ 2 и подтверждается чистильщиком кластеров.
  Длинные Vox sxqvt/xmyyy проверены отдельным guard.
- Сырой WER остаётся чувствительным к формату чисел; `WER_norm` — дополнение,
  а не замена точки отсчёта.
- Дедупликация якоря/окна экономит только короткие реплики; основной объём
  эмбеддингов остаётся.
