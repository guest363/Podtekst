# Политика безопасности

Приложение работает полностью локально; HTTP API слушает только loopback
(`127.0.0.1`) и проверяет заголовки Host/Origin. Приватные данные (аудио,
голосовые отпечатки, списки участников, статистика) не покидают компьютер
пользователя.

## Как сообщить об уязвимости

Пожалуйста, сообщайте **приватно** через GitHub Security Advisories:

https://github.com/guest363/meeting-record/security/advisories/new

Не открывайте публичный issue с деталями уязвимости. Мы отвечаем в течение
14 дней; по согласованию сообщим статус исправления и упомянем автора
(по желанию) в advisory.

## Модель угроз

* API доступен только на `127.0.0.1`, но не имеет авторизации. Приложение
  рассчитано на однопользовательскую машину; не запускайте его на общем
  компьютере, если не доверяете другим локальным пользователям.
* Аудио, расшифровки и голосовые отпечатки хранятся в папке данных приложения
  без шифрования. Защита диска — ответственность ОС и пользователя.
* Скачивание моделей идёт только по HTTPS, файлы проверяются по SHA-256.
