## P1 - следующие

- ✅ **Hotwords через CTC.** Добавляем второй движок GigaAM v3 CTC рядом с основным RNNT. CTC - вариант модели, который выдаёт вероятности букв на каждом шаге звука. Поэтому beam search может давать бонус словам из словаря терминов: аббревиатуры, имена, названия продуктов. Основной RNNT-путь не меняется, второй движок загружается по желанию через карточку моделей.
- ✅ **Уверенность слов.** Показатель уверенности каждого слова из CTC-logprobs. Пометки «проверить вручную» в транскрипте и интерфейсе.
- [ ] **Автопроверка обновлений компонентов.** Мониторинг новых версий моделей (GigaAM, Whisper, Silero, PyAnnote, ERes2NetV2) и ffmpeg. При выходе релиза - уведомление и оценка необходимости обновить манифест моделей и сборки.

## Не в планах

- Облачная расшифровка. Аудио не покидает устройство.
- Интеграции с облачными ИИ-агентами.
- Телеметрия и сбор статистики.
- **Подпись и нотаризация macOS (Apple Developer ID).** Платная программа Apple
  Developer и notarization не окупаются у бесплатного проекта. Пользователь
  проверяет SHA-256 и снимает карантин по `docs/UNSIGNED-INSTALL.md`, а
  обновления подписываются ключом проекта (minisign).
- **Подпись Windows (Authenticode).** Платный сертификат code signing не
  покупаем по той же причине. SmartScreen предупреждает, обновления
  проверяются minisign-подписью.
- **Подавление эха в аудиотракте.** Две попытки не дали результата, код удалён. Замеры на живых стерео (тест-харнесс `MR_DIAG_WAV` оставлен): задержка стабильна (46/58 мс, дрейфа нет), но эхо тихое (-21..-23 дБ) и вперемешку с double-talk - фильтр давал ERLE~0 при 12 дБ на синтетике. Подгонка порогов под конкретную комнату: гейт, помогающий живым, ронял синтетику ниже критерия. Без разнообразного корпуса и условия «не навреди» по построению в тракт не возвращать; дубли давятся на текстовом уровне.
