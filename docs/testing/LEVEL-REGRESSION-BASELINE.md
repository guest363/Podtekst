# Регрессия уровня речи: измерения voice-fix-3

## Статус

Полная последовательность измерена для кандидата L. Последующая правка M устраняет медленное включение усиления и сохраняет исходный канал при отсутствии усиления; её результаты записываются отдельно ниже. **Принятого нового baseline пока нет:** дополнительные проверки разных голосов и VoxConverse выявили ухудшения. Пороги сопоставления и кластеризации по результатам этих прогонов не менялись.

Исторические четыре встречи проверяют совместимость с исходной приёмкой. Их метки соответствуют исходным клипам и не гарантируют разных людей. Дополнительные встречи используют независимое основание различимости голосов; подробнее — [проверка эталона](SYNTH-SPEAKER-GROUND-TRUTH.md). Менять эталон для улучшения метрики нельзя.

## Изменения

- Отбраковка малых кластеров использует уникальную длительность речи: менее 5% или 1,5 с. Повторный auto-k выполняется на оставшихся опорных окнах; удалённые окна затем получают обычное назначение. Ограничения cannot-link и явно заданные границы числа голосов сохраняются. Простое уменьшение k на прежнем дереве может сначала слить два существенных голоса и оставить дальний выброс — этот случай покрыт регрессионным тестом.
- Второй голос с покрытием не менее 25% реплики и 1 с вызывает разделение реплики с сохранением слов и времени. Пересекающиеся окна не удваивают длительность. Сглаживание сохраняет существенные части разделённой реплики.
- Фронтэнд оценивает p10/p90 оконного RMS, использует gate `noise_floor × 2,5`, target RMS 0,1 и ограничение gain 100. Усиление применяется к активным окнам; `ev=diar.agc` содержит floor, speech RMS, gain p50/p95 и долю усиленных окон. `ev=diar.collapse` фиксирует сведение нескольких голосов к одному.
- Нормализованный звук используется для дополнительного прохода VAD и поиска границ. Объединение вероятностей сохраняет речь, найденную на исходном звуке. ASR, проверка профилей и финальные эмбеддинги получают исходный канал. Отдельно исправлен существующий ASR peak-normalizer: ненулевой тихий сигнал больше не отсекается абсолютным порогом.
- Shortcut цифровой тишины в Silero/PyAnnote теперь относится только к нулевым отсчётам. Для ERes2Net восстановлен масштаб PCM перед log-mel/CMN; [совместимость сохранённых профилей](LEVEL-PROFILE-COMPATIBILITY.md) проверена отдельно. `DEFAULT_MATCH_THRESHOLD` не перекалибровывался.
- Генератор поддерживает `--second-speaker-db -18`, сохраняя состав и разметку диалога. Добавлены тесты фронтэнда и env-gated CI с реальными моделями и шестью EN/RU встречами. Строгий gate остаётся красным при нарушении приёмки.

## Кандидат M

Перед изменением усиления добавлен тест начала тихой реплики: RMS первых 200 мс должен быть не ниже 0,075. На прежней экспоненциальной атаке получено 0,02755; тест падал. Линейная огибающая первого/последнего активного окна устраняет задержку без изменения численных gate/target/cap. Дополнительный тест требует побитового сохранения исходного канала, когда усиление не применяется; VAD тогда выполняет один проход. Проверки на реальных наборах ещё не завершены.
