# Лендинг «Подтекст»

Статический сайт без сборки, runtime-зависимостей, внешних шрифтов, cookies и
аналитики. Лежит в `site/`, деплой идёт через GitHub Actions. Навигация работает
с базовым путём `/Podtekst/`: при проверке локально его нужно сохранить.

## Публикация

1. Откройте Settings -> Pages.
2. В Source выберите GitHub Actions.
3. Запустите workflow `pages` или сделайте push в `main`.

Сайт будет доступен по адресу `https://guest363.github.io/Podtekst/`.
Workflow `.github/workflows/pages.yml` публикует содержимое `site/` без сборки.

## Страницы

- `/` - основной экран, приватность, этапы работы, требования, FAQ и поддержка.
- `/support/` - добровольные чаевые и нематериальная помощь проекту.

Скачивание ведёт на последний релиз GitHub. Вложенные страницы используют
относительные пути к `styles.css`, `app.js` и `assets/`.

## Файлы

- `site/index.html` - главная, OG/Twitter-метаданные и JSON-LD.
- `site/support/index.html` - поддержка, условия перевода и хлебные крошки.
- `site/styles.css` - общие токены, типографика, адаптив, стили статей.
- `site/app.js` - доступное мобильное меню и определение ОС для кнопки загрузки.
- `site/assets/screenshots/` - реальные экраны приложения в WebP.
- `site/assets/og-image.png` - соцпревью 1200 x 630.
- `site/robots.txt`, `site/sitemap.xml` - индексация.

При изменении адреса сайта обновите `canonical`, `og:url`, абсолютные URL
изображений и JSON-LD на каждой странице, а также `robots.txt` и `sitemap.xml`.
В `sitemap.xml` добавляются только опубликованные страницы.

## Изображения

Скриншоты лендинга сняты в реальном Svelte UI с синтетическими записями и
обезличенными демонстрационными репликами. HTML-имитации интерфейса не
используются; `docs/render_screenshots.html` служит только для иллюстраций
документации. Для съёмки через Chrome DevTools Protocol можно переиспользовать
`ChromeRunner` и `CdpClient` из `docs/generate_screenshots.py`.

После изменения интерфейса обновите оба WebP и их `alt`, `width`, `height`.
Первый экран предзагружается, остальные скриншоты загружаются лениво. Шаблон
`docs/og-template.html` использует тот же экран расшифровки; из него снимается
`site/assets/og-image.png`.

## SEO-статьи

Требуются пять статей: локальная расшифровка без интернета, аналог Otter без
облака, GigaAM и Whisper, бесплатная офлайн-расшифровка встречи, транскрибация
для психологов и юристов без облака.

Перед написанием обязательно снимается актуальная частотность в Яндекс Wordstat.
На 2026-11-07 чистый браузер перенаправляет Wordstat на авторизацию Яндекс ID,
поэтому числа не получены. Статьи, ссылки на них и записи в sitemap пока не
публикуются: нельзя подставлять оценочные значения. Для продолжения нужен
авторизованный доступ либо экспорт или скриншот результатов Wordstat.
