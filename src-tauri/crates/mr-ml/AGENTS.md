# mr-ml - AGENTS.md

Крейт локального машинного обучения и диаризации на базе ONNX Runtime (CPU).

## 1. Архитектура и строгие инварианты

- **Формат аудио:** все модели и алгоритмы принимают строго **16 000 Гц, 1 канал (моно), f32 [-1.0..1.0]**. Ресемплинг и преобразование каналов выполняются в `mr-audio` до передачи в `mr-ml`.
- **Изоляция математики от файловой системы:** модули инференса и кластеризации не обращаются к диску напрямую. Они принимают срезы памяти `&[f32]` или тензоры и возвращают типизированные структуры.
- **Потокобезопасность:** вызовы инференса `ort::Session` запускаются в пуле блокирующих задач (`tokio::task::spawn_blocking`), чтобы не блокировать асинхронный планировщик Tokio.
- **Память и аллокации:** на горячем пути VAD и извлечения признаков используются предварительно выделенные буферы (`ndarray`).
- **Размерность отпечатков:** голосовые эмбеддинги ERes2NetV2 строго **192-мерные**, с обязательной L2-нормализацией (длина вектора равна 1.0).

## 2. Ключевые файлы

- `src/lib.rs` - фасад крейта, публичные структуры диаризации и сегментации.
- `src/cluster.rs` - complete linkage через nearest-neighbor chain O(n²), плоская матрица расстояний и силуэт-оценка фрагментов.
- `src/onnx/vad.rs` - детектор речи Silero VAD v6.2 с сохранением скрытого состояния (state) между окнами 32 мс и pre-roll 64 мс.
- `src/onnx/rnnt.rs` - акустическая модель GigaAM-v3 e2e RNNT (энкодер, предиктор, джойнер). Декодер и джойнер работают в один поток для исключения накладных расходов синхронизации.
- `src/onnx/whisper.rs` - мультиязычный ASR Whisper large-v3-turbo.
- `src/onnx/embed.rs` - модель ERes2NetV2 (3D-Speaker) для извлечения 192-мерных отпечатков.
- `src/onnx/segmentation.rs` - PyAnnote 3.0 Powerset: окна 10 с с шагом 1 с, маски перекрытий и локальные метки спикеров.
- `src/onnx/features.rs` - вычисление 80-полосных лог-мел спектрограмм.

## 3. Состояние и известные ограничения (не «чинить» без задачи)

- **Whisper greedy search:** декодер Whisper использует жадный поиск (`greedy`). Поиск по лучу (`beam search`) отключен осознанно, чтобы экономить оперативную память на CPU. Не переписывать на beam search без отдельной задачи.
- **Однопоточный joint GigaAM:** джойнер оперирует матрицами малого размера, где затраты на синхронизацию потоков превышают выигрыш в скорости.

## 4. Локальная верификация

```bash
# Быстрые юнит-тесты и тесты математики кластеризации (без моделей)
cargo test -p mr-ml --lib

# Строгая проверка clippy
cargo clippy -p mr-ml --all-targets --locked -- -D warnings

# Проверка инференса на реальных моделях (требует скачанных моделей и WAV)
cargo test -p mr-ml --features onnx --test onnx_real -- --nocapture
```
