# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-25

Первый публичный релиз.

### Добавлено

* Запись встреч с раздельными каналами микрофона и системного звука на Linux.
* Локальная расшифровка: GigaAM-v3 e2e RNNT int8 (русский) и Whisper large-v3-turbo int8.
* Диаризация и голосовые отпечатки ERes2NetV2 192-dim.
* Голосовые пакеты (`.voicepack.zip` / `.voicepack.json`) и база знаний из Markdown.
* Tauri-окно, трей, глобальный хоткей, автозапуск.
* Импорт и расшифровка готовых аудио/видеофайлов.
* Онбординг с очередью загрузки базовых моделей (~300 МБ).
* Android-сборка (экспериментальная), см. `ANDROID.md`.

### Изменено

* Убрана интеграция Markdown-базы знаний (`knowledge_dirs`); голосовые пакеты
  остаются основным способом вести список участников.

### Исправлено

* Windows: лишнее окно консоли при запуске из Проводника теперь скрывается;
  окно приложения открывается по ширине контента (920×860 вместо 1280×860).
* Расшифровка тихой короткой речи: отсекается AAC priming, VAD видит тихие
  реплики, короткие тихие фрагменты склеиваются перед ASR, для тихих сегментов
  включается штраф на blank. Проверено на видео со счётом «шесть, семь, восемь,
  девять» — все четыре слова теперь в тексте.
* Релиз публикует один пакет на платформу: Windows `.exe`, macOS `.dmg`,
  Linux `.AppImage` + `SHA256SUMS` (вместо 21 ассета).

### Известные ограничения

* Живой захват системного звука на macOS и Windows пока в разработке.
* Android: только микрофон, расшифровка экспериментальная.
* Релизные бинарники не подписаны; macOS Gatekeeper и Windows SmartScreen
  могут показать предупреждение.
* Linux-бинарники собраны на Ubuntu 24.04 (glibc 2.38+), macOS — Apple Silicon
  и 13.4+: этого требует предсобранный ONNX Runtime.
