## P1 - следующие

- ✅ **Hotwords через CTC.** Добавляем второй движок GigaAM v3 CTC рядом с основным RNNT. CTC - вариант модели, который выдаёт вероятности букв на каждом шаге звука. Поэтому beam search может давать бонус словам из словаря терминов: аббревиатуры, имена, названия продуктов. Основной RNNT-путь не меняется, второй движок загружается по желанию через карточку моделей.
- ✅ **Уверенность слов.** Показатель уверенности каждого слова из CTC-logprobs. Пометки «проверить вручную» в транскрипте и интерфейсе.
- ✅ **Проверка компонентов при выпуске.** Версии моделей (GigaAM, Whisper, Silero, PyAnnote, ERes2NetV2, Qwen) и ffmpeg закреплены за сборкой: ревизии апстримов, файлы и контрольные суммы записаны в манифест моделей и в список версий ffmpeg. CI-монитор следит за новыми версиями, валидация сверяет ревизии, релизный гейт не пропускает сборку с расхождением. Клиент версии в фоне не проверяет.

а метрику можно проверить на сигнале. Всё считается локально; спецификация -
`docs/features/speech-metrics/SPEC.md`, исследования - в Obsidian, проект «Подтекст».

**Tier A - детерминированно, без ML (дни работы):**
- [x] Из таймкодов и диаризации: доля речи и баланс участия (union интервалов, а не сумма), длина реплик и монологов, перехваты, латентность ответа, мёртвый воздух.
- [x] Одновременная речь по пересечению реплик; перехваты - между разными каналами. Для mono/mix перехваты помечены как недоступные, а не нулём.
- [x] Из WAV: флаги качества - клиппинг, SNR, узкая полоса, дисбаланс каналов; расчёт по каждому каналу отдельно.

- [ ] Маркеры на таймлайне плеера.

**Tier B - просодия из WAV, чистый Rust поверх существующего FFT:**

## Не в планах

- Облачная расшифровка. Аудио не покидает устройство.
- Интеграции с облачными ИИ-агентами.
- Телеметрия и сбор статистики.
- **Подпись и нотаризация macOS (Apple Developer ID).** Платная программа Apple
  Developer и notarization не окупаются у бесплатного проекта. Пользователь
  проверяет SHA-256 и снимает карантин по `docs/UNSIGNED-INSTALL.md`, а
  обновления подписываются ключом проекта (minisign).
- **Подпись Windows (Authenticode).** Платный сертификат code signing не
  покупаем по той же причине. SmartScreen предупреждает, обновления
  проверяются minisign-подписью.
- **Подавление эха в аудиотракте.** Две попытки не дали результата, код удалён. Замеры на живых стерео (тест-харнесс `MR_DIAG_WAV` оставлен): задержка стабильна (46/58 мс, дрейфа нет), но эхо тихое (-21..-23 дБ) и вперемешку с double-talk - фильтр давал ERLE~0 при 12 дБ на синтетике. Подгонка порогов под конкретную комнату: гейт, помогающий живым, ронял синтетику ниже критерия. Без разнообразного корпуса и условия «не навреди» по построению в тракт не возвращать; дубли давятся на текстовом уровне.
- **Распознавание эмоций на реплику (GigaAM-emo).** В деловой речи большинство реплик
  нейтральные, а согласие разметчиков по эмоции в спонтанной речи низкое: эталона, по
  которому можно проверить качество, нет. На дальнем поле с перекрытиями модель
  схлопывается в «нейтрально», а редкие срабатывания объясняются громкостью микрофона и
  перекрытием. AI Act ст. 5(1)(f) запрещает распознавание эмоций на рабочем месте и в
  образовании. Вместо ярлыка считаются измеримые метрики речи - см. раздел «Метрики речи».
