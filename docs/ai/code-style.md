# Свод правил (P1–P12)

Единственный источник правды по правилам разработки. `AGENTS.md` держит только короткие
инварианты и ссылки, `docs/ai/workflow.md` — процесс; полный текст правил живёт здесь.
Расхождение копий — главная причина устаревших инструкций.

Нарушение P1–P12 — блокер. Идентификаторы стабильны: на `P1`…`P12` ссылаются код,
комментарии, ревью и сообщения коммитов.

## Что ловит инструмент, а что остаётся на ревью

| Правило | Механизм | Не покрыто |
|---|---|---|
| P11 (комментарии) | `./scripts/p11-diff.sh --check` в `verify.sh` | смысл «зачем» — на ревью |
| P12 (Zero-Leak) | CI `hygiene`, gitleaks, шаблон PR | тексты вне git |
| P9 (контракты) | тесты контрактов и форматов | совместимость по смыслу |
| P5 (кроссплатформенность) | CI: Linux, macOS, Android; release-бандлы | ручные сценарии устройств |
| Стиль фронта | `yarn lint`, `yarn check` (Biome, svelte-check) | разметка и `<style>` в `.svelte` |
| P1–P4, P6–P8, P10 | тесты, CI, ревью | архитектурные границы и размер diff |

Линтер не заменяет правило: он ловит только формализованную часть. Диагностику не
подавляют — чинят код.

## P1 — DRY и единый источник правды

Форматы (`voiceprints.json` v3, `.transcript.json`, `models-manifest.json`) имеют одно
каноническое описание; Rust и тесты — единственная реализация. Дублирование существующей
логики запрещено: сначала проверьте код и крейтовые `AGENTS.md`.

## P2 — YAGNI и простота (Ponytail)

Стандартная библиотека и текущие зависимости вместо новых крейтов. Функциональность — за
cargo-параметрами (`onnx`, `tauri-ui`); базовая сборка без системных зависимостей.
Минимальный diff, который полностью закрывает задачу.

## P3 — Изоляция UI от ядра

HTTP REST API (`mr-app`) — единственный мост между Web UI и ядром. Никаких ML-импортов
в HTTP-слое, никакой файловой логики в математике.

## P4 — Статические ассеты вне кода

Web UI — только `ui/web/static/` (сборка Svelte); исходники — `ui/web/frontend/src/`
(Svelte 5 + TS + CSS Cascade Layers). Имена сборки детерминированы (`css/app.css`,
`js/app.js`, без хешей) — их знает `static_body` в `mr-app/src/http/mod.rs`: он отдаёт
файлы из `ui/web/static` по расширению, а `css/app.css` и `js/app.js` дополнительно вшиты
`include_bytes!` как аварийный fallback на случай отсутствующего каталога. Новые файлы
статики регистрируются там же.

## P5 — Кроссплатформенность без исключений

Пути — `PathBuf`; захват аудио — через `mr-audio` (WASAPI Loopback / CoreAudio +
ScreenCaptureKit / PipeWire); специфика операционных систем — за `#[cfg(target_os)]`.

## P6 — Минимум внешних процессов

Основной путь — нативные библиотеки (libpulse через dlopen, symphonia).
Исключения: `ffprobe`/`ffmpeg` (длительность медиа и контейнеры без демуксера symphonia),
`pactl`/`pw-record`/`parec` (если libpulse отсутствует), `gsettings` (горячие клавиши
GNOME), открытие браузера и папок.

## P7 — Корректное завершение

IPC-сервер и HTTP останавливаются вместе с процессом; запись финализирует WAV-заголовки.

## P8 — Модули до 300–400 строк

Роутер HTTP (`http/mod.rs`) и конвейер (`transcribe/mod.rs`) — координаторы, чьи ветки
разнесены в соседние файлы; сами решения держим компактными.

## P9 — Обратная совместимость

CLI-флаги (`--toggle/--start/--stop/--tray/--web/--port`), REST-контракты и форматы файлов
не ломаются без мажорной версии. Новые поля — аддитивно, со значениями по умолчанию.

## P10 — Root Cause

Чинить причину на том слое, где она возникает; не маскировать её в вызывающем коде или
интерфейсе. Проверка — запуск на реальной записи, а не только зелёный тест гипотезы.

## P11 — Строгая типизация; комментарии только «ЗАЧЕМ»

Каждый комментарий приходится поддерживать вместе с кодом: пересказ кода устаревает и
вводит в заблуждение. По умолчанию — 0 комментариев: код самодокументируется типами и
именами.

Запрещены пересказы действий кода, дублирующие docstrings, и разделители (`// ---`).
Разрешены только обоснования:

- ограничение платформы, контракт формата, калибровка порога с источником замера;
- `SAFETY:` / `shortcut: <ограничение>, <когда апгрейдить>`;
- ссылки на правила (`[P3]`, `[P9]`).

Язык — русский. Перед завершением задачи diff проверяется
`./scripts/p11-diff.sh --check` (входит в `./scripts/verify.sh --fast`).

## P12 — Безопасность данных и Zero-Leak

Аудио, голосовые отпечатки и статистика — только локально.

Запрещено утекать личные данные в PR, коммиты, issue, код, комментарии и тесты: никаких
реальных имён файлов и записей, имён людей, тем бесед или фрагментов речи. Сценарии, ошибки
и замеры описываются строго через обезличенные технические характеристики: канал
(моно/стерео), хронометраж, число спикеров, частота, параметры перекрытий.

Исходящий трафик: скачивание открытых весов моделей, проверка последнего релиза на GitHub
и — по явному согласию — загрузка подписанного обновления (без аудио и идентификаторов).
Автоустановка обновлений без действия пользователя не выполняется.

## Фронтенд

Svelte/TS проверяется Biome (`yarn lint`) и `svelte-check` (`yarn check`). Конвенции —
`ui/web/frontend/AGENTS.md`: `type` вместо `interface`, `const`-стрелки, `import type`,
без `any` и лишних `as`, kebab-case имён файлов. Здесь не дублируются.
