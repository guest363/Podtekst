# Проверка метрик на реальных записях

Дата: 14.11.2026. Сборка: ветка `feat/speech-metrics`, релизный бинарник.
Данные: локальные записи владельца, в репозиторий не попадают [P12].
Ниже только технические параметры: канал, хронометраж, число реплик.

## Метод

1. `GET /api/transcript/metrics` на запущенном приложении.
2. Независимый расчёт тех же метрик на Python из `.transcript.json`:
   union интервалов, доли, монологи со склейкой 1.5 с, паузы ≥ 5 с.
3. F0 - независимый оценщик на автокорреляции (не YIN), по кадрам 40 мс.
4. Синтетический стерео-WAV с тонами 200/300 Гц - `mr-metrics/tests/analyze_wav.rs`.

## Результаты

| Запись | Реплик | Речь | Доли | Монолог | Пауза | Время ответа |
|---|---|---|---|---|---|---|
| моно, 110 мин, импорт MP3 | 286 | 6139 с | совпали до 0.001 | 368.14 с = 368.14 с | 22.22–33.68 с = эталон | 0.2 с |
| стерео, 69 мин, WAV | 570 | 3292 с | совпали до 0.001 | 50.26 с = 50.26 с | 251.45–257.00 с = эталон | 5.1 с |
| синтетика 11 с, 2 канала | 3 | 6 с | 0.667 / 0.333 | — | 4.0–9.0 с | < 0.1 с |

Сумма долей речи во всех случаях 1.0000. Для моно получены ожидаемые
`mono_no_overlap` и `no_audio` (импорт MP3, просодия не считается).
Для стерео - `channel_balance`: каналы микрофона и системы различаются по уровню,
это факт записи, а не ошибка расчёта.

## F0

- Синтетический тон 200 Гц: медиана в пределах 5 Гц.
- Реальная речь, стерео: API 125.0 Гц против независимой автокорреляции 137.9 Гц
  (разница 9.4 %, около 1.7 полутона).

Причина расхождения - разные оценки и разный отбор кадров: YIN и автокорреляция
по-разному ведут себя на шумных и тихих кадрах. Для личной базовой линии это
допустимо: сравнивается один и тот же алгоритм с самим собой. Для сравнения
разных людей абсолютные Гц не используются.

Что ужесточено после первого прогона: F0 считается только по кадрам выше −45 dBFS
с чистотой ≥ 0.3; порог пауз остался отдельным, чтобы не завышать их долю.

## Ограничения

- Praat/openSMILE не установлены: сверка с эталонной реализацией не проведена.
- Проверен один голос на записи; выборка мала для оценки разброса F0.
- Доля пауз чувствительна к порогу энергии; число показывается только при
  `quality.grade = good` и трактуется как относительный показатель.
- Ручная разметка 200 реплик и регрессионный корпус 10-20 записей ещё не сделаны.
