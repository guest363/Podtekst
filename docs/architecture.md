# Архитектура

Карта системы для людей и агентов. Термины — `CONTEXT.md`, правила — `docs/ai/code-style.md`,
локальные детали — `AGENTS.md` крейтов.

## Стадии конвейера

Любая запись проходит последовательные фазы:

1. **Захват (Capture).** Микрофон и система пишутся раздельно на 16 кГц. Цифровые дубли
   сокращаются до одного исходного канала; при акустическом эхе каналы сохраняются,
   микрофон обрабатывается VAD-гейтом и дедупликацией.
2. **VAD.** Нарезка дорожек на речевые фрагменты Silero VAD v6.2 с pre-roll 64 мс; длинные
   ASR-окна делятся по минимуму вероятности речи во второй половине окна.
3. **ASR.** Локальное распознавание текста: GigaAM RNNT для русского, Whisper turbo для
   остальных языков.
4. **Diarization & Embedding.** PyAnnote Segmentation 3.0 размечает локальных спикеров и
   перекрытия в окнах 10 с с шагом 2 с; ERes2NetV2 3D-Speaker извлекает 192-мерные векторы
   только из речи вне перекрытий.
5. **Clustering & Matching.** Average linkage (UPGMA) O(n²), силуэт-оценка фрагментов и
   спикеров, ограниченное венгерское назначение локальных спикеров глобальным кластерам,
   пословная атрибуция через интервальное дерево и сопоставление с эталонами.
6. **Artifact Generation.** Атомарная запись протокола (`.md`), чистого текста (`.txt`) и
   разметки (`.transcript.json`).

Детали стадий: `src-tauri/crates/mr-app/AGENTS.md` (координация и конвейер),
`src-tauri/crates/mr-ml/AGENTS.md` (инференс и кластеризация),
`src-tauri/crates/mr-audio/AGENTS.md` (захват и декодирование).

## Соответствие UI ↔ Rust ↔ файлы

| Концепция в UI | Тип / модуль в Rust | Файл / хранилище | Пояснение |
|---|---|---|---|
| Запись в списке | `mr_app::media_registry::MediaItem` | `<storage>/<name>.wav` | Записанный или импортированный аудиофайл |
| Протокол со спикерами | `mr_app::transcribe::Transcript` | `<storage>/<name>.md` | Markdown с таймкодами и именами |
| Текст для нейросетей | `String` (чистый текст) | `<storage>/<name>.txt` | Без разметки, для отправки в LLM |
| Структура расшифровки | `mr_app::transcribe::TranscriptJson` | `<storage>/<name>.transcript.json` | JSON с таймкодами, словами, эмбеддингами и additive-полями `silhouette` |
| Каталог участников | `mr_packs::PeopleManifest` | `<app_data>/packs/<id>/people.json` | Участники и привязка к сэмплам |
| База голосовых векторов | `mr_packs::VoiceprintsV3` | `<app_data>/packs/<id>/voiceprints.json` | 192-мерные векторы, формат v3 |
| Каталог ИИ-моделей | `mr_models::Manifest` | `models-manifest.json` в коде | Ссылки, SHA-256 и размеры |
| Скачанные веса | `PathBuf` к ONNX-файлам | `<app_data>/models/<id>/` | Проверенные `.onnx` файлы |
| Настройки приложения | `mr_app::config::AppConfig` | `<app_data>/config.json` | Устройства, пороги и язык |

## Диаризация: текущая конфигурация

Опоры AHC извлекаются внутри установленных реплик из не более 6 с чистой речи; короткие
опоры допускаются от 1 с. Локальные окна 1,8 с уточняют границы по центроидам опор.
Маска VAD/PyAnnote исключает неречевые и перекрывающиеся отсчёты из эмбеддингов и расчёта
длительности. Размеченные фрагменты образуют интервальное дерево: слово получает спикера
по покрытию, реплика делится при смене спикера; недостающие границы интерполируются.
Покрытие речи по стадиям — объединение интервалов без меток спикеров: оно локализует
потери, но не заменяет DER и исходную разметку. Абляции — `src-tauri/crates/mr-app/AGENTS.md`.

## Инварианты домена

- **Разделение стерео и моно.** В стерео сохраняются микрофон и система, включая запись с
  колонками. Только цифровые дубли обрабатываются как один канал. В моно речь делится по
  паузам с извлечением вектора каждого фрагмента.
- **Индекс канала.** `channel` в документе и образцах указывает на канал исходного файла,
  даже если для обработки выбран один канал цифрового дубля.
- **Порог имени.** Для назначения имени нужно не менее 2 с использованного чистого аудио без
  повторного учёта перекрывающихся окон; исключение — кластер от 0,9 с при почти точном
  совпадении с профилем (similarity ≥ 0,95 и margin ≥ 0,05), чтобы образец, снятый с
  короткой реплики, узнавался в этой же записи. Для проверки именованной реплики после слияний —
  от 1,5 с; детали — `src-tauri/crates/mr-app/AGENTS.md`. Противоречие профилю снимает имя;
  другое имя назначается только через общий matcher с его порогами и проверкой
  неоднозначности. Образцы и центроиды карточек пересобираются по проверенным репликам.
- **Аддитивные форматы.** `voiceprints.json` v3 и `.transcript.json` — публичный контракт:
  поля не удаляются и не меняются без миграции (P9), новые поля добавляются аддитивно.
- **Zero-Leak.** Аудио, отпечатки и статистика остаются локально (P12,
  `docs/ai/code-style.md`).
