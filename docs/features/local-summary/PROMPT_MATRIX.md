# Prompt matrix (§7)

Контракт матрицы зафиксирован в [`prompt-matrix.json`](prompt-matrix.json).
G1 реализует победителя `hybrid-v2`: системные инварианты дословно, секции каталога,
strict task-формат только для `role=task`, DATA внутри nonce-маркеров.

Матрица **не выполнялась** в G1: нет загруженной модели, а числа нельзя выдумывать.
Исполнение 3 формулировок × 4 фикстуры (`meeting/scrum/legal/lecture`) и 2 повтора
победителя — G5. Критерий выхода: победитель не теряет валидные задачи и секции;
`prompt_version` пишется в артефакт; проигравшая формулировка не оправдывает парсер.
