# Шаблон AGENTS.md для крейта или зоны

Скопируйте в `<путь>/AGENTS.md`, если у зоны есть существенные правила, которых нет в общей
документации. Описывать очевидную структуру не нужно: файл создаётся ради инвариантов,
карты файлов и особенностей, а не ради оглавления.

README зоны — конвенции, API и примеры (канон для людей и агентов). `AGENTS.md` — только
правила изменения, состояние и долги, без дублей README. Бюджет — 120 строк
(`./scripts/ai-docs-check.sh`).

```markdown
# <зона> — AGENTS.md

Назначение в 1–2 предложениях; термины — из `CONTEXT.md`.

## Инварианты

- Что нельзя нарушать и почему (формат, платформа, контракт). Ссылки на P1–P12 при уместности.

## Ключевые файлы

- `src/...` — ответственность модуля.
- `src/...` — точка входа или координатор.

## Состояние и долги

- Заглушки, временные решения, известные ограничения — чтобы агент не «чинил» отключённое
  без задачи.

## Проверка

- Точечные команды зоны; полный гейт — `./scripts/verify.sh --rust` или `--ui`.

## Связи

- Соседние крейты, форматы, внешние контракты, спеки `docs/features/*`.
```
