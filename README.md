# Подтекст (Podtekst)

**Локальная запись звонков и расшифровка речи на вашем компьютере.**

## Ключевые возможности

- **Раздельный захват.** Микрофон пишется в левый канал, системный звук - в правый. Поддерживаются PipeWire, PulseAudio, WASAPI Loopback и ScreenCaptureKit. При выводе звука на колонки приложение отсекает эхо в микрофоне VAD-гейтом и очищает текстовые дубли. Исходные каналы сохраняются для разделения спикеров. Только цифровые дубли сводятся в один канал. Для лучшего разделения голосов используйте наушники.
- **Полная локальность.** Распознавание речи и подготовка итогов выполняются на вашем компьютере. Аудиозаписи, расшифровки и голосовые профили не передаются в сеть.
- **Русская речь: GigaAM-v3.** Модель от SberDevices с квантованием INT8 занимает 226 МБ. Она быстро работает на процессоре без дискретной видеокарты.
- **Словарь терминов и уверенность слов.** Второй проход GigaAM CTC учитывает до 500 профессиональных терминов, имён и фраз сленга. Модель оценивает уверенность каждого слова и исправляет созвучные ошибки.
- **Локальные итоги встреч (Qwen).** Языковая модель Qwen3-4B Instruct формирует структурированный протокол: краткие тезисы, ключевые решения и задачи с исполнителями и таймкодами. Доступны семь шаблонов: рабочая встреча, скрам, юридическая беседа, лекция, консультация психолога, личные заметки и универсальный разбор. Модель также умеет стилистически править текст стенограммы. Обработка выполняется через llama.cpp на процессоре или с аппаратным ускорением GPU (Metal на macOS, Vulkan на Linux и Windows).
- **Очередь расшифровки.** Добавляйте файлы перетаскиванием или через кнопку выбора. Приложение расшифровывает записи по очереди и показывает статус текущей задачи. Задачу можно снять отдельно или очистить очередь целиком.
- **Мультиязычность: Whisper Turbo.** Модель Whisper large-v3-turbo (INT8, около 1,09 ГБ) распознаёт речь на английском и более чем 30 других языках.
- **Диаризация и узнавание коллег.** Связка Silero VAD и PyAnnote Segmentation 3.0 находит границы фраз и перекрытия голосов. Модель ERes2NetV2 (3D-Speaker) строит отпечатки голосов, а приложение сопоставляет их с сохранёнными голосовыми пакетами (Voice Packs).
- **Синхронная запись экрана.** Рабочий стол или окно звонка записываются вместе с микрофоном и системным звуком. Видео и звук сохраняются в один MP4-файл. Захват работает на Linux (GNOME Shell / PipeWire), Windows (ffmpeg gdigrab) и macOS (ffmpeg avfoundation). ffmpeg ставится одной кнопкой из настроек. Встроенный плеер синхронизирует видео с репликами и таймкодами.
- **Готовые материалы для базы знаний.** Конвейер расшифровки создаёт рядом с исходным файлом:
  - `.md` - протокол со спикерами и таймкодами для Obsidian, Notion или Logseq;
  - `.txt` - чистый текст для локальных языковых моделей;
  - `.transcript.json` - реплики, таймкоды, спикеры и пословная уверенность CTC.
  При запросе локальных итогов языковая модель формирует:
  - `.summary.md` - структурированный конспект с решениями и задачами;
  - `.summary.json` - машиночитаемые итоги с разделами и таймкодами цитат.

## Быстрый старт

### Вариант 1. Готовые сборки
Скачайте установочный файл для вашей операционной системы со страницы [Releases](https://github.com/guest363/podtekst/releases):
- **Linux:** `.AppImage`
- **macOS:** `.dmg` (или запуск через `run.command`)
- **Windows:** `.exe` (NSIS-установщик; SmartScreen может показать предупреждение: смотрите [docs/UNSIGNED-INSTALL.md](docs/UNSIGNED-INSTALL.md))
- **Android:** `.apk` (пакет для архитектуры ARM64)

#### macOS: если после установки «невозможно открыть»

Сборки сознательно не подписаны платным сертификатом Apple Developer ID.
Проверьте контрольную сумму SHA-256 файла `.dmg` по `SHA256SUMS`, скопируйте приложение в
`/Applications` и снимите флаг карантина:

```bash
xattr -dr com.apple.quarantine /Applications/Podtekst.app
open /Applications/Podtekst.app
```

Также открыть файл можно через интерфейс: правый клик по приложению в Finder →
**«Открыть»** → подтвердить **«Открыть»** в окне системы.
Подробная инструкция: [docs/UNSIGNED-INSTALL.md](docs/UNSIGNED-INSTALL.md).
Обновления проверяются по встроенной minisign-подписи ключом проекта.

При первом запуске macOS запросит доступ к микрофону, а при первой записи -
к экрану и системному звуку. Подтвердите оба разрешения: без доступа к экрану
приложение не сможет захватить речь собеседников.

#### macOS: звук собеседников и запись экрана

Системный звук захватывается через ScreenCaptureKit: звук из
Zoom, Google Meet или Telegram попадает в правый канал без драйвера BlackHole.
Слушайте встречу в наушниках: при выводе звука на колонки микрофон неизбежно улавливает
голоса собеседников, и приложению приходится подавлять эхо.

1. Запустите запись и подтвердите доступ в меню «Системные настройки» →
   «Конфиденциальность и безопасность» → «Запись экрана и системного аудио».
2. Перезапустите приложение, если система этого потребует.
3. Пока доступа нет, в окне горит статус «Системный звук: нужно разрешение»,
   а запись временно идёт только с микрофона.

Виртуальный аудиокабель остаётся запасным вариантом. Если ScreenCaptureKit
недоступен на вашей системе, установите **BlackHole 2ch** (`brew install blackhole-2ch`),
создайте многовыходное устройство в «Настройке Audio-MIDI» и выберите
BlackHole источником системного звука в настройках приложения.

### Вариант 2. Запуск из исходников

```bash
git clone https://github.com/guest363/podtekst.git
cd podtekst
./run.sh
```

Приложение откроется в нативном окне. Для запуска в режиме веб-сервера без графических библиотек WebKit и GTK:

```bash
./run.sh --web
```

Консоль управления доступна в браузеру по адресу `http://127.0.0.1:8765`.

### Системные требования

- **Процессор:** современный x86_64 или Apple Silicon.
- **macOS на Apple Silicon:** запускайте нативную arm64-сборку. Бинарник x86_64
  под транслятором Rosetta работает значительно медленнее; скрипт `run.command`
  предупреждает об этом.
- **Оперативная память:** от 1,5 ГБ для GigaAM-v3, от 4 ГБ для Whisper. Для локальных итогов на Qwen3-4B требуется от 6,5 ГБ свободной памяти (рекомендуется от 12 ГБ общей памяти устройства).
- **Диск:** около 530 МБ для базового комплекта моделей (Silero VAD, GigaAM RNNT + CTC, PyAnnote 3.0, ERes2NetV2). С моделью Whisper - около 1,6 ГБ. С моделью итогов Qwen3-4B (2,33 ГБ) - около 4,1 ГБ. Для пакета ускорения Vulkan требуется ещё около 45 МБ.
- **Linux:** Ubuntu 22.04+ или glibc 2.35+. Для сборки нативного окна установите пакеты:
  ```bash
  sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libssl-dev libxdo-dev
  ```
- **Форматы аудио:** MP3, WAV, M4A, OGG, Opus, FLAC и MP4 декодируются нативно. Для контейнеров MKV, WebM, MOV и AVI нужен ffmpeg: его можно установить кнопкой в настройках приложения.

1. **Манифест моделей (`src-tauri/crates/mr-models/models-manifest.json`):** Версии файлов, официальные зеркала (Hugging Face / ModelScope) и контрольные суммы SHA-256 зафиксированы в репозитории. ## Управление и горячие клавиши

Глобальная комбинация клавиш (работает из любого окна):  
**`Ctrl+Shift+R`** (на macOS - **`Cmd+Shift+R`**) - начать или остановить запись.

### Команды командной строки и автоматизация

```bash
# Управление записью и окном через IPC
./run.sh --toggle          # Переключить запись (старт или стоп)
./run.sh --start           # Начать запись
./run.sh --stop            # Остановить запись
./run.sh --show            # Показать скрытое окно приложения
./run.sh --hide            # Свернуть окно в системный трей
./run.sh --quit            # Завершить работающий процесс

# Режимы запуска
./run.sh --tray            # Запустить в фоновом режиме в системном трее
./run.sh --web             # Запустить в режиме веб-интерфейса в браузере
./run.sh --dev             # Запустить в dev-режиме: профиль dev-opt, подробные логи и артефакты
./run.sh --build           # Принудительно пересобрать интерфейс и Rust-ядро

# Диагностика и обслуживание
./run.sh --diagnostics                   # Собрать zip-архив диагностики и вывести путь к нему
./run.sh --diagnostics --with-dev-logs   # Собрать архив диагностики с хвостом dev-логов

# Пакетная расшифровка аудиофайла без открытия графического окна
./run.sh --transcribe meeting.mp3 [--engine auto|gigaam|whisper] [--language ru|en|auto] [--min-speakers N] [--max-speakers N] [--ctc auto|on|off]
```

Для управления автозапуском при входе в систему используйте флаги бинарника:
`podtekst --autostart-on` и `podtekst --autostart-off`.

## Приватность и безопасность

- **Локальная обработка данных:** все нейросети и вычисления работают на вашем оборудовании.
- **Отсутствие телеметрии:** приложение не собирает аналитику, диагностику использования или списки участников.
- **Сетевой трафик отправляется только по явному действию пользователя:**
  1. **Загрузка моделей.** Открытые веса скачиваются с официальных репозиториев авторов (Hugging Face, ModelScope) по нажатию кнопки в настройках.
  2. **Загрузка вспомогательных компонентов.** Утилита FFmpeg и GPU-пакет Vulkan для ускорения итогов скачиваются из официальных релизов по запросу пользователя.
  3. **Проверка обновлений.** При запуске приложение проверяет номер последней версии на GitHub. Загрузка обновления (Linux: AppImage, macOS: `.app`, Windows: NSIS) запускается только по кнопке. Пакет проверяется minisign-подписью ключом проекта. Без согласия пользователя обновления не ставятся.

> **Внимание:** соблюдайте законы о тайне переговоров и предупреждайте собеседников о записи встречи. Подробнее - в [PRIVACY.md](PRIVACY.md).

## Разработка и участие

Стек: **Rust** (MSRV 1.92, Tokio, Symphonia, Ort, llama.cpp) + **Tauri v2** + **Svelte 5** (Vite, TypeScript, Biome).

```bash
# Запуск модульных тестов ядра и математики диаризации
cargo test --workspace --locked --manifest-path src-tauri/Cargo.toml

# Проверка кода линтером clippy (строгий режим без предупреждений)
cargo clippy --workspace --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings

# Проверка оконного слоя Tauri и системного трея
cargo clippy -p mr-app --features tauri-ui --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings

# Проверка форматирования Rust-кода
cargo fmt --all --manifest-path src-tauri/Cargo.toml -- --check

# Проверка типов и сборка фронтенда
cd ui/web/frontend && yarn install --immutable && yarn lint && yarn check && yarn build
```

## Стоя на плечах великих

Приложение работает локально и без платных подписок благодаря исследователям и инженерам, открывшим свои модели и исходный код. Благодарим авторов проектов и библиотек:

### Модели и исследования
- [GigaAM](https://github.com/salute-developers/GigaAM) (SaluteDevices / Sber AI) - за открытые веса и качественное распознавание русской речи, работающее быстро даже на процессоре ноутбука.
- [Whisper](https://github.com/openai/whisper) (OpenAI) - за мультиязычную архитектуру, позволяющую расшифровывать встречи на десятках языков без внешних серверов.
- [PyAnnote](https://github.com/pyannote/pyannote-audio) (Hervé Bredin / onnx-community) - за нейросетевую модель сегментации речи и точное разделение перекрывающихся голосов.
- [Qwen](https://github.com/QwenLM/Qwen) (Alibaba Cloud) - за открытую языковую модель Qwen3-4B Instruct, формирующую структурированные итоги встреч локально на CPU и GPU.
- [Silero VAD](https://github.com/snakers4/silero-vad) (Silero Team / Александр Вейсов) - за быстрый детектор речи, который отсекает паузы и бережёт ресурсы компьютера.
- [3D-Speaker & ERes2NetV2](https://github.com/alibaba-damo-academy/3D-Speaker) (Alibaba Tongyi Speech Lab / ModelScope) - за модели голосовых отпечатков, позволяющие разделять и узнавать участников разговора.
- [ONNX Runtime](https://onnxruntime.ai/) (Microsoft) - за производительный движок исполнения нейросетей на процессоре и видеокарте.
- [llama.cpp](https://github.com/ggerganov/llama.cpp) (Georgi Gerganov) - за быстрый и экономичный локальный инференс языковых моделей на CPU и GPU.

### Библиотеки Rust
- [ort](https://github.com/pykeio/ort) - за надёжные привязки к ONNX Runtime для безопасного кода на Rust.
- [symphonia](https://github.com/pdeljanov/Symphonia) - за декодер звука на чистом Rust без тяжёлых сторонних C-зависимостей.
- [hound](https://github.com/ruuda/hound) - за стабильную запись и чтение аудиофайлов формата WAV.
- [opus-decoder](https://github.com/shogo4204/opus-decoder) - за прямое чтение голосовых заметок из Telegram и других мессенджеров.

### Платформа и интерфейс
- [Tauri](https://tauri.app/) - за легковесную архитектуру без оверхеда Electron, благодаря которой бинарник весит считанные мегабайты.
- [Svelte](https://svelte.dev/) - за отзывчивый интерфейс без виртуального DOM и удобство разработки.
