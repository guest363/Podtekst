# Метрики словаря и hotwords, 2026-11-22

Статус: локальный синтетический прогон, не релизный гейт. Инструмент — `src-tauri/crates/mr-eval` (`podtekst-eval hotwords`).

## Корпус

TTS-голос `Microsoft Irina`, 16 кГц моно, вымышленные термины «альфа», «бета», «гамма». Два набора:

- основной: 3 клипа с терминами, 2 похожих слова, 2 обычные фразы;
- алиасов: 2 клипа, где произнесено «альфат»/«бетту», а ожидается «альфа»/«бета».

## Результаты

Алиасы, GigaAM RNNT, словарь `альфат => альфа`, `бетту => бета`:

| Вариант | Recall | WER | CTC |
|---|---:|---:|---:|
| `off`, пустой словарь | 0% | 25% | да |
| `ctc-off`, только пост-замена | 100% | 0% | нет |
| `on`, CTC + словарь | 100% | 0% | да |

Основной корпус, словарь из трёх терминов:

| Вариант | Recall | False insertions | WER |
|---|---:|---:|---:|
| `off` | 66,7% | 0 | 3,3% |
| `on` | 66,7% | 0 | 3,3% |
| `ctc-off` | 66,7% | 0 | 3,3% |

Свип бонуса `on-b2.5`, `on-b3`, `on-b4` на этом корпусе дал одинаковые метрики: TTS-клипы слишком простые, запаса по recall нет. Механизм свипа работает, но для выбора бонуса нужен реальный шумный корпус.

## Ограничения

- Один синтетический голос, чистая студийная запись; абсолютные значения WER несравнимы с публичными наборами.
- Проверен только GigaAM; Whisper-путь покрыт юнит-тестами пост-замены и общим кодом, но не отдельным аудиопрогоном.
- CTC перерешивает только слова, уже попавшие в гипотезу RNNT; вставку новых слов он не делает.
- Алиасы «только регистр» (`api => API`) остаются подсказкой CTC без автозамены.

Запуск и формат манифеста — `src-tauri/crates/mr-eval/README.md`.
