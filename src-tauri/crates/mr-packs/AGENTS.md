# mr-packs - AGENTS.md

Крейт управления голосовыми пакетами, профилями участников и базой знаний биометрии.

## 1. Архитектура и строгие инварианты

- **Канонический формат:** голосовые отпечатки хранятся строго по схеме версии 3 (`voiceprints.json` v3) с указанием пространства признаков (`embedding_space`). Любые изменения формата требуют миграции (P1, P9).
- **Изоляция пользовательских данных:** папки пакетов хранятся в `<app_data>/packs/<id>/` (`people.json`, `voiceprints.json`, `snippets/*.wav`). Личные данные не должны попадать в систему контроля версий (P12).
- **Экспорт и обмен:** поддерживается упаковка голосового пакета в архив `.voicepack.zip` или `.voicepack.json` для переноса базы участников между компьютерами.

## 2. Ключевые файлы

- `src/lib.rs` - фасад крейта, загрузка пакетов и управление активным каталогом.
- `src/manifest.rs` - схемы данных участников и структуры векторов отпечатков.
- `src/transfer.rs` - логика импорта и экспорта пакетов через ZIP-архивы.

## 3. Локальная верификация

```bash
# Тесты сериализации манифестов и распаковки пакетов
cargo test -p mr-packs --lib

# Строгая проверка clippy
cargo clippy -p mr-packs --all-targets --locked -- -D warnings
```
