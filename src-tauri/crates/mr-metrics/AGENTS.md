# mr-metrics - AGENTS.md

Слой измеримых метрик речи: взаимодействие, просодия, качество записи.
Эмоции, arousal, «стресс» и «вовлечённость» не измеряются: у них нет эталона в сигнале.

## Инварианты

- **Метрика - это формула и протокол проверки.** Всё, что нельзя воспроизвести из файла,
  остаётся интерпретацией и в артефакт не попадает.
- **Абсолютные F0 и энергия не сравниваются между людьми и устройствами.** В UI - только
  перцентиль внутри встречи или отклонение от личной базовой линии.
- **Перекрытия только при двух и более различимых каналах.** Если у реплик меньше
  двух каналов (mono, mix, dedupe), перехваты не считаются; предупреждение
  `mono_no_overlap` вместо нулей. Одновременная речь считается по репликам и для
  одного канала остаётся метрикой пересечения интервалов, но не перехватов.
- **Вход - `.transcript.json` + WAV 16 кГц.** Не-WAV и видео дают `prosody_unavailable`:
  внешние декодеры в этот крейт не тянем.
- **L0 считается по каналам отдельно.** SNR, полоса, клиппинг и баланс не смешивают
  кадры разных каналов; цифровая тишина не даёт опорного шума. В итог идут худший
  SNR и лучшая полоса активных каналов, чтобы узкий системный звук не прятал микрофон.
- **Пороги и версии.** `SCHEMA_VERSION` и константы в модулях - часть контракта:
  изменение порога меняет числа и требует нового замера.
- **Никаких персональных данных в тестах.** Только синтетические тона, тишина и
  обезличенные WAV из публичных фикстур [P12].

## Модули

| Файл | Ответственность |
|---|---|
| `src/lib.rs` | Публичные типы, `analyze`, медианы и перцентили |
| `src/interaction.rs` | Доли речи, монологи, перехваты, латентность, паузы, навигация |
| `src/prosody.rs` | YIN, F0 в полутонах, энергия, доля пауз |
| `src/quality.rs` | Клиппинг, SNR, полоса, дисбаланс каналов, `grade` |

## Проверка

```bash
cargo test -p mr-metrics --locked --manifest-path src-tauri/Cargo.toml
cargo clippy -p mr-metrics --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings
cargo fmt --all --manifest-path src-tauri/Cargo.toml -- --check
```

`tests/analyze_wav.rs` пишет синтетический стерео-WAV с известными тонами и проверяет
доли, F0, паузу и полосу. Пороги: F0 ±1 Гц на синтетике, тест-ретест - побайтовое
совпадение JSON.
