# Meeting Recorder - Правила проекта (Antigravity workspace rules)

Этот файл - входная точка для агента в рабочей области. Полная карта проекта находится в **`AGENTS.md`** в корне репозитория: прочтите его первым.

## Контекст по задаче

- **Доменные сущности:** перед работой с терминами сверяйтесь с `CONTEXT.md`.
- **Перед изменением крейта:** прочитайте его локальный `AGENTS.md` (`src-tauri/crates/*/AGENTS.md` или `ui/web/frontend/AGENTS.md`).
- **Регламент и верификация:** процесс работы (Track 1 / Track 2) и команды проверки описаны в `docs/ai/workflow.md`.
- **Мобильная версия:** специфика Android описана в `ANDROID.md`.

## Основные правила (кратко)

1. **[Zero-Leak]** Аудио, голоса и статистика - только локально. Запрещено выводить личные имена, названия файлов и темы встреч в PR, коммиты, issue, код и тесты (P12).
2. **[Root Cause]** Исправляйте ошибку на базовом слое, а не маскируйте в вызывающем коде (P10).
3. **[No Warnings]** Код компилируется без предупреждений Clippy; фронтенд проходит проверку типов без ошибок.
4. **[Ponytail]** Минимальный рабочий diff без лишних абстракций и зависимостей (P2).
