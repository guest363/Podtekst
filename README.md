# Запись встреч (Meeting Recorder) 0.1.0

[![CI](https://github.com/guest363/meeting-record/actions/workflows/ci.yml/badge.svg)](https://github.com/guest363/meeting-record/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/guest363/meeting-record)](https://github.com/guest363/meeting-record/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Нативное кроссплатформенное приложение для записи звонков и локальной ИИ-расшифровки
(Linux / macOS / Windows). Один бинарник; FFmpeg нужен только для
видео-контейнеров MKV/WebM/MOV/AVI — аудио-форматы декодируются нативно.

- **Раздельные каналы**: микрофон — в левый канал, собеседники — в правый (WASAPI Loopback / CoreAudio Tap / PipeWire, без виртуальных кабелей).
- **Локальный ИИ**: GigaAM-v3 (русский язык, SOTA) и Whisper-turbo (30+ языков) через ONNX Runtime прямо на вашем процессоре. Ни один байт не уходит в облако.
- **Диаризация и голоса**: разбиение участников по репликам и узнавание знакомых коллег (мульти-прототипные голосовые отпечатки, подключаемые Voice Packs).

> **Запись разговоров.** Записывайте только те разговоры, на которые у вас есть
> согласие участников. Законы о записи зависят от страны и региона.

## Быстрый старт

```bash
git clone https://github.com/guest363/meeting-record.git
cd meeting-record
./run.sh
```

Требования:

- **Rust** (минимум 1.92 по зависимостям; точная версия закреплена в
  `rust-toolchain.toml`, ставится rustup'ом автоматически);
- для пересборки Web UI — **Node.js ≥ 20.19 / ≥ 22.12 и Yarn 4** (`corepack enable`).
  Готовая сборка уже в репозитории (`ui/web/static`), поэтому пока исходники фронта
  не менялись, Node не нужен;
- для нативного окна — системный WebView, в Debian/Ubuntu один раз:
  `sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev`
  (macOS: WKWebView из системы; Windows: WebView2 из системы).
  Без системных пакетов доступен лёгкий режим `./run.sh --web` (только HTTP + браузер);
- для моделей нужно ~1.5 ГБ диска и ~4 ГБ свободной RAM при расшифровке Whisper.
  Первый запуск без моделей работает, но расшифровка попросит скачать их;
- Linux: Ubuntu 24.04+ / glibc 2.38+; macOS 13.4+ (Apple Silicon);
  Windows 10/11 с WebView2 — это требует предсобранный ONNX Runtime.

```bash
./run.sh                  # Нативное окно Tauri + API http://127.0.0.1:8765
```

Откройте `http://127.0.0.1:8765` в браузере — это Studio Console
(запись, расшифровка, спикеры, модели, голосовые пакеты).

### Windows и macOS

- **Windows**: двойной клик по `run.bat` (или установщик из
  [Releases](https://github.com/guest363/meeting-record/releases)).
  Сейчас работают импорт готовых файлов и расшифровка; живой захват WASAPI — в разработке.
- **macOS**: двойной клик по `run.command` в Finder.
  Сейчас работают импорт готовых файлов и расшифровка; живой захват CoreAudio — в разработке.
- Готовые пакеты (`.exe`, `.dmg`, `.AppImage`) — во вкладке
  [Releases](https://github.com/guest363/meeting-record/releases).
  Бинарники 0.1.0 не подписаны: macOS Gatekeeper и Windows SmartScreen могут
  показать предупреждение.

## Захват звука собеседников (настройка 1 раз)

Приложение сразу пишет ваш микрофон. Захват системного звука — нативно,
без виртуальных кабелей и прав администратора:

- **Linux**: работает сразу (PipeWire / PulseAudio мониторятся автоматически).
- **macOS**: живой захват системного аудио пока в разработке — импортируйте запись файлом.
- **Windows**: живой захват WASAPI пока в разработке — импортируйте запись файлом.

## Локальная расшифровка в текст (ИИ)

1. **Скачивание моделей** (один раз, ~250 МБ для русского, ~1.3 ГБ с Whisper):
   карточка «Модели ИИ» → «Скачать». Проверка SHA-256 и докачка при обрыве — автоматически.
2. **Расшифровка**:
   - кнопка «Текст & Спикеры» у любой сохранённой записи;
   - или перетащите аудио/видео прямо в окно: MP3, WAV, M4A, OGG/Opus, FLAC и MP4
     декодируются нативно; MKV/WebM/MOV/AVI — через установленный `ffmpeg`;
   - или из терминала: `./run.sh --transcribe встреча.mp3 [--engine auto|gigaam|whisper]`.
3. **Результат**: рядом с файлом сохраняются:
   - `<имя>.md` — текст встречи с таймкодами и именами участников;
   - `<имя>.txt` — чистый текст;
   - `<имя>.transcript.json` — структурированные реплики и отпечатки голосов.

## ИИ-модели: архитектура, квантование и обновление

Вся обработка звука выполняется на 100% локально через **ONNX Runtime (CPU)** без облачных запросов и без необходимости в дискретной видеокарте:

```
Аудиодорожка (16 кГц)
   │
   ▼
[Silero VAD v6] ─────────► Нарезка аудио на речевые сегменты без пауз и шумов
   │
   ├──────────────────────────────┬──────────────────────────────┐
   ▼                              ▼                              ▼
[GigaAM-v3 e2e RNNT]   [Whisper large-v3-turbo]        [ERes2NetV2 3D-Speaker]
(Основной ASR, RU)     (Мультиязычный ASR, 30+ языков) (Голосовые отпечатки, 192-dim)
   │                              │                              │
   └───────────────┬──────────────┘                              ▼
                   ▼                                  Кластеризация спикеров
            Текст реплик ───────────────────────────► Итоговый отчет (.md/.json)
```

### Используемые модели и квантование

- **GigaAM-v3 e2e RNNT (INT8)** — ~226 МБ (основной ASR для русского языка):
  - **Архитектура**: Conformer-Transducer ~242M параметров (SberDevices). Включает энкодер, 1-слойный LSTM-декодер и совместную сеть (Joint network). Жадный авторегрессионный декодинг без beam-search и внешней языковой модели.
  - **Квантование**: веса квантованы в `INT8` (энкодер 224 МБ, декодер 1.1 МБ, joint 0.7 МБ). Занимает в 4 раза меньше памяти по сравнению с FP32 (~1 ГБ) при сохранении точности SOTA для русской речи.
- **Whisper large-v3-turbo (INT8)** — ~1.08 ГБ (мультиязычный ASR / 30+ языков):
  - **Архитектура**: Sequence-to-Sequence Transformer (OpenAI). В версии Turbo декодер сжат с 32 слоёв до 4 слоёв при сохранении 32-слойного энкодера `large-v3`, что обеспечивает ускорение в 4–6 раз.
  - **Квантование**: `INT8` (энкодер 645 МБ, объединённый декодер с KV-кэшем 440 МБ).
- **Silero VAD v6 (FP32)** — ~2.3 МБ (детектор речевой активности):
  - **Архитектура**: потоковая рекуррентная нейросеть со скрытым состоянием `[2, 1, 128]`, обрабатывающая аудио фреймами по 32 мс (512 сэмплов). Отсекает тишину, дыхание, эхо и клики.
- **ERes2NetV2 3D-Speaker (FP32)** — ~68 МБ (голосовые отпечатки):
  - **Архитектура**: ERes2NetV2 (Alibaba 3D-Speaker, `speech_eres2netv2_sv_zh-cn_16k-common`,
    Apache-2.0), 17.9M параметров. Вход — 80-канальный kaldi-fbank (hann, CMN),
    выход — 192-мерный L2-нормализованный вектор. SOTA на коротких фрагментах (1–3 с).
  - **Точность**: совпадение с эталоном 3D-Speaker — косинус
    1.000 (тест `onnx_real::eres2netv2_parity_with_official_reference`); разные
    дикторы ≤ 0.22, один голос ≥ 0.48 на фрагментах от 1.5 с.
  - **GPU (опционально)**: cargo-фичи `ort-cuda` / `ort-directml` / `ort-coreml`
    в `mr-ml` подключают аппаратные Execution Providers с прозрачным CPU-fallback.

### Как устроено обновление моделей при выходе новых версий

1. **Декларативный манифест (`models-manifest.json`):**
   Версии моделей, источники и контрольные суммы SHA-256 описаны в едином манифесте,
   вшитом в приложение и обновляемом вместе с релизом.
2. **Бесшовная докачка и проверка целостности:**
   При обновлении файл скачивается через HTTP Range частями во временный `.part`-файл. Атомарная замена файла в `<app_data>/models/<id>/` и регистрация в `state.json` происходят только после успешной проверки SHA-256.
3. **Совместимость баз голосов при смене архитектуры (`embedding_space`):**
   Модели эмбеддингов дикторов помечены тегом векторного пространства (сейчас
   `"eres2netv2-192-v1"`). Профили старых пространств (например, `pyannote-256-v1`)
   без исходных сэмплов не пересчитываются: при первом старте с новой моделью они
   удаляются (оригинал — в `voiceprints.v2.bak`), база `voiceprints.json`
   переводится в v3, и образцы голоса собираются заново через обычное сохранение.

## Управление и горячие клавиши

Глобальный хоткей (Tauri-сборка): **`Ctrl+Shift+R`** (`Cmd+Shift+R` на Mac) — старт / стоп.

Полезные команды CLI:

```bash
./run.sh --toggle    # Переключить запись (удобно назначить на системную горячую клавишу)
./run.sh --tray      # Фоновый режим (одиночный экземпляр)
./run.sh --web       # Открыть интерфейс в браузере
```

## Open Source: голосовые пакеты, модели и поддержка проекта

- **Голосовые пакеты (Voice Packs):** базы участников и голосов хранятся отдельно от кода
  в `<app_data>/packs/<id>/` (`people.json`, `voiceprints.json` v3, `snippets/*.wav`).
  Импорт/экспорт `.voicepack.zip`, включение/отключение пакетов — в интерфейсе.
- **Модели ИИ:** реестр `src-tauri/crates/mr-models/models-manifest.json`
  (GigaAM-v3 RNNT int8, Whisper-turbo, Silero VAD, ERes2NetV2-эмбеддинги) с версиями,
  SHA-256 и официальными источниками (HuggingFace / GitHub авторов моделей).
- **Поддержка проекта:** [Т-Банк](https://t.tb.ru/pm_short/8nsXmBmCIGj). В UI есть кнопка
  `Поддержать разработку`.

## Приватность

Ни один байт аудио или текста не покидает ваш компьютер. Единственный исходящий
трафик — скачивание открытых весов моделей из официальных источников, перечисленных
в `models-manifest.json`. Телеметрии нет. Голосовые отпечатки и списки участников
хранятся только локально.

Приложение не является медицинским, юридическим или кадровым инструментом;
ответственность за согласие участников записи и соблюдение местных законов
лежит на пользователе. Подробнее — `PRIVACY.md`.

## Разработка

```bash
cargo test --workspace --locked --manifest-path src-tauri/Cargo.toml   # unit-тесты
cargo clippy --workspace --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings
cargo clippy -p mr-app --features tauri-ui --all-targets --locked --manifest-path src-tauri/Cargo.toml -- -D warnings
cd ui/web/frontend && yarn install --immutable && yarn check && yarn build  # фронт
```

Живые ONNX-тесты (нужны скачанные модели + WAV, иначе пропускаются):

```bash
MR_MODELS_DIR=/путь/к/models MR_TEST_WAV=/путь/к/запись.wav \
  cargo test -p mr-ml --features onnx --test onnx_real -- --nocapture
```

Подробности архитектуры — в `AGENTS.md`.
